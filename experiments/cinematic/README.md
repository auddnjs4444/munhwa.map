# Cinematic Gwangju — 1단계 시안 (충장로)

사용자가 준 "Cinematic Gwangju" 콘셉트 이미지를 실제 웹 화면으로 옮기는 실험입니다. 1단계는 **사진 한 장 기반의 시네마틱 첫 화면 + 충장로 선택 + 오른쪽 황금 패널**만 다룹니다. 실시간 3D는 쓰지 않습니다(2단계에서 `../city3d`와 연결 검토).

- 브랜치 `experiment/cinematic-gwangju` (main 병합·배포 금지, 사용자 승인 전까지)
- 본 사이트 코드·데이터는 건드리지 않습니다. 기록 원문은 `../city3d/data/content.json`(기존 `data/places.json`·`spots.json`·`memory-stories.json`의 복사본)을 읽습니다.

## 열어보기

```bash
cd /Users/melong/수어지도 && python3 -m http.server 8010
# → http://localhost:8010/experiments/cinematic/
```

- `?hero=acc` (기본) · `?hero=mountains` · `?hero=boulevard` — 배경 사진 후보 비교
- `#place/chungjang` — 충장로 선택 상태로 바로 열기
- `?noanim=1` — 카메라·전환 애니메이션 없이 (동작 줄이기 설정과 같음)

## 사진 (저장소에 넣지 않음)

배경·장면 사진은 사용자가 준 참고 캡처(네이버 블로그 화면 캡처, 게시 권한 미확인)에서 사진 영역만 잘라 `assets/`에 두었고, `.gitignore`로 **저장소에 올라가지 않습니다.** 내부 시안 확인용이며 운영 사이트에 쓰려면 권한을 확인한 사진으로 교체해야 합니다. 사진이 없으면 화면에 안내가 뜹니다.

| 파일 | 원본 | 용도 | 한계 |
|---|---|---|---|
| `assets/acc-night.jpg` | 참고 사진 03 | 기본 배경(해질녘, 국립아시아문화전당 일대) | 촬영 방향 미확정. 709×557px 캡처라 1440px 화면에서 2배 확대 |
| `assets/overlook-mountains.jpg` | 참고 사진 08 | 배경 후보(도시 조망·산) | 낮 사진을 CSS로 해질녘 톤 보정. 창문·거리 조명은 없음 |
| `assets/aerial-boulevard.jpg` | 참고 사진 10 | 배경 후보(대로 항공) | 낮 사진, 구간 미확정 |
| `assets/chungjang-night.jpg` | 참고 사진 01 | 충장로 선택 장면 | 개별 상점 위치 미확인 |

사진 위에 **위치 핀을 두지 않습니다.** 촬영점·방향·건물 대응을 확인할 수 없기 때문이며, 실제 위치는 지명 수어 지도(`../../#map/chungjang-ro`)로 연결합니다. 충장로 선택은 같은 사진 안을 이동하는 것이 아니라 충장로 거리 사진으로 **장면 전환**합니다.

## 화면 구성 (1440×900 기준)

- 왼쪽 70%: 사진 + 등급 보정 오버레이(남색 하늘·따뜻한 지평선) + 비네트·그레인 + 느린 드리프트(켄번스) + 커서 시차(±14px) + 선택 시 1.08배 확대와 따뜻한 빛 번짐
- 큰 타이포그래피: 손글씨 한 줄(기존 팀 수첩 메모 원문: "친지들 모이는 곳 — 캔모아 충장로점 · 충파 앞 · A님 · 광주 23년") + 장소명 104px + 금색 가는 선 + 작은 안내문
- 하단 장소 메뉴(충장로·금남로·5·18민주광장·ACC·금남로 나비정원): 충장로만 장면·기록이 있고 나머지는 '준비 중'(5·18민주광장은 열람 확인 문구 유지)
- 오른쪽 30% 황금 패널: 둥근 이전/다음/닫기, 영문 CHUNGJANGNO, 제목, 세로형 영상 자리(충장로 영상은 아직 없어 '준비 중' — 다른 지역 영상으로 대신하지 않음), 광주 동구/기록 수, 장소 기억(메모 1 + 인터뷰 기록 2 + 캔모아 이야기 인용 1, 모두 원문·출처 표기), 본 사이트 캔모아 기록(`#spot/canmore`)·지명 수어 지도 링크, 태그
- 모바일(≤767px): 풍경이 먼저, 선택하면 아래에서 시트(52dvh, 펼치면 90dvh)

## 아직 안 된 것 / 콘셉트 이미지와의 차이

- 콘셉트의 아름다움은 생성형 이미지의 것입니다. 실제 사진이 작고(709px) 낮 사진이 대부분이라 창문 조명·산·도시 입체감을 한 장에 담은 해질녘 항공사진은 없습니다. 권한이 확인된 고해상도 해질녘 항공사진이 들어오면 같은 구조로 바로 바꿔 끼울 수 있습니다.
- 사진 위 위치 핀·경계선은 의도적으로 그리지 않았습니다(검증 불가).
- 충장로 수어 영상이 없어 패널의 영상은 자리표시자입니다.
- 금남로·5·18민주광장·ACC·나비정원 장면은 2단계(3D 연결) 또는 사진·기록 확보 후.

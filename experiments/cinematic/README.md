# Cinematic Gwangju — 캔모아 중심 장소 탐험 (experiment)

사용자가 확정한 "Cinematic Gwangju" 첫 화면 위에, **충장로 캔모아를 거점으로 다른 장소의 기록으로 이어지는 탐험 구조**를 얹은 실험입니다. 실시간 3D는 쓰지 않습니다.

- 브랜치 `experiment/cinematic-gwangju` (main 병합·배포는 사용자 승인 전까지 금지)
- 본 사이트 코드·데이터는 건드리지 않습니다. **원본 데이터(`data/spots.json`·`places.json`·`memory-stories.json`)를 그대로 읽습니다.** 복사본·창작 문장 없음.

## 열어보기

```bash
cd /Users/melong/수어지도 && python3 -m http.server 8010
# → http://localhost:8010/experiments/cinematic/
```

- `#place/canmore` — 캔모아 선택 상태로 바로 열기. `#place/chungu`(충우 앞), `#place/palace-bakery`, `#place/geumnam-park`, `#place/518-democracy-square`, `#place/acc` 등 항목 id 그대로
- `?noanim=1` — 전환 애니메이션 없이 (동작 줄이기 설정과 같음)

## 흐름

1. **첫 화면** — 참고 사진 08(도심·무등산 방향 조망)을 블루아워 톤으로 가득 채우고 「손으로 부르는 광주」, 보조 문구 「농인의 기억으로 다시 만나는 광주」(사용자 지정), 본 사이트 소개 첫 문단(원문), 「광주 탐험하기 →」. 오른쪽 패널은 열지 않습니다.
2. **광주 탐험하기 → 충장로 → 캔모아** — 충장로 거리 사진(참고 사진 01)으로 장면 전환, 왼쪽에 팀 수첩 메모 한 줄(원문)과 「캔모아」, 오른쪽 황금 패널에 캔모아 장소 기억 원고(`memory-stories.json`, 12문단 원문, 3문단까지 보이고 「이야기 전체 읽기」) + 수첩 메모.
3. **함께 둘러볼 장소 →** — 패널 안에서 목록으로 전환. **가까운 장소**(캔모아에서 직선 450 m 이내, 좌표 확인된 곳) / **더 둘러볼 곳**(충장로 바깥, 거리순). 선택하면 패널·장면이 바뀌고, 「캔모아로 돌아가기」가 머리글과 본문에 생깁니다.
4. 하단 칩(캔모아·충우 앞·궁전제과·금남로공원·5·18민주광장·ACC)과 상단 「지역 선택 +」는 우선 장소만, 전체는 패널 목록에서.

| `places.json` 충장로 memories[0] | 수첩 메모 "친지들 모이는 곳" | 왼쪽 손글씨 줄 |
| `spots.json` hubs.canmore.nearby (11곳) | 주변 장소: 궁전제과·충장의 집·일이일오·5·18기록관·무등갤러리·이화갤러리·금남로공원·예향식당·뼈대있는집·사직공원·광주공원 | 번호·주소·좌표 그대로. 본 사이트 `#spot/canmore/<id>` 링크 |
| `places.json` memory_entries | 궁전제과·ACC 기록은 장소명으로 자동 연결, 충우 앞·전일빌딩/금남로 기록은 '기억만 있는 곳' 항목 | 화자·본문·인용·출처 표기 |
| `spots.json` hubs.hosijeong + nearby | 동명동 호시정 거점과 주변(여행자의 집·에브르인테라스·레이트 에이엠·캐치스피자·ACC·치른시빌) | 모두 '더 둘러볼 곳'(530–990 m). 캔모아 바로 주변이 아님을 거리로 표시 |
| `places.json` 5·18민주광장 | 열람 확인 문구(원문) → 기록 준비 중 | 좌표는 OSM 광장 중심 사용(아래 참고) |

좌표가 데이터 파일에 없는 곳만 `PRESENT`에 출처와 함께 둡니다: 충우 앞 = OSM 광주우체국 node/368876980(충장로2가, 궁전제과 옆), 5·18민주광장 = OSM relation/19102230 중심. 금남로공원은 `spots.json`의 지점(금남로3가 20-2, poi)이 OSM 공원 폴리곤 중심과 25 m 차이로 확인됨. '금남로 나비정원'이라는 별칭은 사용자 확인 + 여행 정보 사이트의 "금남나비정원 미디어아트" 소개(공식 자료 재확인 필요)에 근거합니다.

거리는 **직선거리(haversine)** 만, 좌표가 확인된 곳만 표시합니다. 도보 경로·소요 시간은 표시하지 않습니다. 사진 위 핀·경계선·미니맵 없음.

## 장면 사진 규칙

- 충장로에 있는 장소(캔모아·충우 앞·궁전제과·전일빌딩→충장로 기억)는 **충장로 거리 사진**을 배경으로 쓰되, 크레딧에 "선택한 장소 자체의 사진이 아님"을 적습니다.
- ACC는 참고 사진 03. 그 외(금남로공원·5·18민주광장·갤러리·공원·동명동)는 **사진이 없으므로 첫 화면의 도심 조망을 배경**으로 두고 "이 장소의 사진은 아직 없음"을 표기합니다. 다른 지역 사진을 그 장소 사진으로 쓰지 않습니다.
- 지명 수어 영상은 이 화면에 넣지 않습니다(장소 기억과 혼동 방지). 각 항목의 「지명 수어 지도에서 보기」로 연결만 합니다. 영상 플레이어는 해당 장소의 영상이 생길 때만 표시(현재 0개).

## 검증 방법

1440×900·390×844 캡처는 macOS WebKit(`WKWebView`)을 화면 밖에서 띄워 찍었습니다(Chrome 미설치, 브라우저 패널 캡처는 800×500으로 축소됨). 전환 애니메이션은 끝 상태로 고정. 클릭 흐름(탐험하기 → 캔모아 → 목록 → 충우 앞 → 캔모아로 돌아가기 → 5·18 열람 확인 → ACC → 금남로공원 → 궁전제과 → Esc)은 Chromium 패널에서 상태·해시·링크를 확인했습니다.

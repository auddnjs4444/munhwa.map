# Cinematic Gwangju — 1단계 시안

사용자가 준 "Cinematic Gwangju" 콘셉트 이미지를 실제 웹 화면으로 옮기는 실험입니다. 1단계는 **사진 한 장 기반의 시네마틱 첫 화면 → 광주 탐험하기 → 충장로 선택 + 오른쪽 황금 패널**만 다룹니다. 실시간 3D는 쓰지 않습니다(2단계에서 `../city3d`와 연결 검토).

- 브랜치 `experiment/cinematic-gwangju` (main 병합·배포 금지, 사용자 승인 전까지)
- 본 사이트 코드·데이터는 건드리지 않습니다. 기록 원문은 `../city3d/data/content.json`(기존 `data/places.json`·`spots.json`·`memory-stories.json`의 복사본)을 읽습니다.

## 열어보기

```bash
cd /Users/melong/수어지도 && python3 -m http.server 8010
# → http://localhost:8010/experiments/cinematic/
```

- `?hero=mountains` (기본) · `?hero=acc` · `?hero=boulevard` — 배경 사진 후보 비교
- `#explore` — 탐험 화면으로 바로 열기, `#place/chungjang` — 충장로 선택 상태로 바로 열기
- `?noanim=1` — 카메라·전환 애니메이션 없이 (동작 줄이기 설정과 같음)

## 화면 3단계 (1440×900 기준)

| 상태 | 화면 | 문구 출처 |
|---|---|---|
| 첫 화면 `intro` | 무등산·도심 항공사진(참고 사진 08)을 블루아워 톤으로 보정해 가득 채우고, 왼쪽 아래에 제목 **손으로 부르는 광주**, 손글씨 한 줄, 소개문, **광주 탐험하기** 버튼 | 본 사이트 `index.html` 소개 섹션 원문 그대로: "어디에도 기록되지 않은 이름", "광주의 농인들은 충장로, 무등산, 양림동 같은 장소들을 …", "GWANGJU SIGN LANGUAGE MAP · GSL®/2026" |
| 탐험 화면 `explore` | 같은 풍경 위에 상단 브랜드, 왼쪽 아래 "주요 장소", 하단 장소 메뉴(충장로·금남로·5·18민주광장·ACC·금남로 나비정원) | 충장로만 열리고 나머지는 '준비 중' 표시 |
| 장소 화면 `place` | 충장로 거리 사진(참고 사진 01)으로 장면 전환, 손글씨 한 줄(팀 수첩 메모 원문 "친지들 모이는 곳") + 지명 104px + 금색 선, 오른쪽 30% 황금 패널 | 패널 내용은 `content.json` 원문(메모 1 + 인터뷰 기록 2 + 캔모아 이야기 1), 영상은 없어 '준비 중', 5·18민주광장은 열람 확인 문구 유지 |

연출: 켄번스 드리프트(28s) + 커서 시차(±14px) + 선택 시 1.08배 확대·장면 크로스페이드(1.6s)·따뜻한 빛 번짐. 사진 위에 **위치 핀·행정경계는 그리지 않습니다**(촬영점·방향 미확정). 실제 위치는 지명 수어 지도(`../../#map/chungjang-ro`) 링크로 연결합니다.

블루아워 보정(`cinematic.css`의 `.grade-bluehour`): 낮 사진에 남색 multiply 그라데이션(하늘 0–22%, 능선 22–38%)을 얹고, 주봉 위 하늘에 노을빛 radial·능선 띠를 screen으로 더한 뒤 도심에는 색온도만 올립니다. 사진에 없는 창문 조명이나 건물은 그리지 않습니다.

## 사진 (저장소에 넣지 않음)

배경·장면 사진은 사용자가 준 참고 캡처(네이버 블로그 화면 캡처, 게시 권한 미확인)에서 사진 영역만 잘라 `assets/`에 두었고, `.gitignore`로 **저장소에 올라가지 않습니다.** 내부 시안 확인용이며 운영 사이트에 쓰려면 권한을 확인한 사진으로 교체해야 합니다. 사진이 없으면 화면에 안내가 뜹니다.

## 검증 방법

1440×900·390×844 캡처는 macOS WebKit(`WKWebView`)을 화면 밖에서 띄워 찍었습니다(Chrome 미설치, 브라우저 패널 캡처는 800×500으로 축소됨). 캡처 시 전환 애니메이션을 끝 상태로 고정했습니다. 상태 전환·패널 열림·해시(`#explore`, `#place/chungjang`)·키보드(Esc, ←/→)는 브라우저 패널에서 동작 확인.

## 아직 안 된 것 / 콘셉트 이미지와의 차이

- 콘셉트의 아름다움은 생성형 이미지의 것입니다. 실제 사진이 작고(709px) 낮 사진이라 창문 조명·도시 입체감은 색온도 보정으로만 암시합니다. 권한이 확인된 고해상도 해질녘 항공사진이 들어오면 같은 구조로 바로 바꿔 끼울 수 있습니다.
- 사진 위 위치 핀·경계선·미니맵은 의도적으로 그리지 않았습니다(검증 불가).
- 충장로 수어 영상이 없어 패널의 영상은 자리표시자입니다.
- 금남로·5·18민주광장·ACC·나비정원 장면은 승인 후(2단계 또는 사진·기록 확보 후).

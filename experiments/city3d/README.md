# 3D 탐험 프로토타입 — 손으로 부르는 광주

광주 동구 핵심 축(충장로 – 금남로 – 5·18민주광장 – 국립아시아문화전당 ACC)을 양식화한 3D 도시로 그리고, 장소를 고르면 카메라가 그곳으로 날아가 오른쪽 패널에 세로형 수어 영상과 장소 기억을 띄우는 **실험용 엔트리**입니다.

- 본 사이트(`/index.html`, `app.js`, `spots.js`, `story.js`)와 코드·화면을 공유하지 않습니다. 이 폴더만 지우면 흔적 없이 사라집니다.
- 브랜치 `experiment/city3d`에서만 작업하며 main에 합치지 않습니다.
- 공개 사이트에 게시하는 단계가 아니라 설득력 있는 프로토타입을 보는 단계입니다.

## 열어보기

```bash
cd /Users/melong/수어지도 && python3 -m http.server 8010
# → http://localhost:8010/experiments/city3d/
```

- `#spot/chungjang` 같은 주소로 특정 스팟을 바로 열 수 있습니다 (`chungjang`, `geumnam`, `square`, `acc`, `jeonil`, `dongmyeong`).
- `?noanim=1`은 카메라 이동을 즉시 점프로 바꿉니다(동작 줄이기 설정과 같음). `?rafshim=1`은 애니메이션 프레임이 멈추는 테스트 환경용입니다.

## 기술 구조

| 층 | 내용 |
|---|---|
| 렌더링 | MapLibre GL JS 4.7.1 (unpkg CDN, 키 없음). 벡터 타일 서버 없이 GeoJSON 소스만 씁니다. |
| 지형 데이터 | OpenStreetMap에서 추출한 `data/*.geojson` (건물 1,159 · 도로 408 · 물 5 · 녹지 38 · 랜드마크 16 · ACC 구역 1). 출처·검증·한계는 `data/DATA.md`. |
| 3D | `fill-extrusion` 건물(높이: OSM height/levels → 없으면 용도별 단순화 모델, `city3d.js`의 `DEFAULT_H`), 충장로 간판 상자(fill-extrusion), ACC 빛 상자·금남로 가로등(circle). |
| 연출 | 늦은 블루아워 팔레트(`city3d.js`의 `C`), 뷰포트 고정 조명, `sky`(피치 70° 이상에서 지평선 위로 보임), CSS 비네트·그레인. 선택한 스팟 반경의 건물은 `feature-state`로 금빛 빛 웅덩이처럼 밝아집니다. |
| 카메라 | `flyTo`(2.4–3.0초, 멀면 곡선을 크게). 패널 폭/시트 높이만큼 `padding`을 주어 대상이 가려지지 않게 합니다. 동작 줄이기 설정이면 즉시 이동. |
| UI | 상단 '탐험 +' 메뉴, 하단 스팟 내비(01–05), 오른쪽 유리 패널(모바일은 바텀시트), 키보드(←/→ 이전·다음, Esc 닫기), 주소 해시. |
| 콘텐츠 | `data/content.json` — 기존 `data/places.json`·`spots.json`·`memory-stories.json`의 원문을 그대로 옮긴 것. 지어낸 설명은 없고, 없는 기록은 "기록 준비 중"으로 표시. 5·18민주광장은 본 사이트와 같은 열람 확인 문구를 거칩니다. |

### 파일

- `index.html` — 마크업 (하늘, 지도, 상단·하단 내비, 탐험 메뉴, 패널)
- `city3d.css` — 스타일 (데스크톱 오른쪽 패널 / ≤767px 바텀시트)
- `city3d.js` — 데이터 가공, MapLibre 스타일, 카메라, 선택·패널·내비 로직
- `data/spots3d.json` — 스팟 정의 (좌표·검증 상태·출처·카메라). 나비정원은 `coords: null`, `unverified`.
- `data/content.json` — 패널 콘텐츠 (원문 복사본 + 출처 필드)
- `data/*.geojson`, `data/DATA.md`, `data/convert_osm.py` — 지리 데이터와 변환 스크립트

| 02 금남로 | OSM 도로 '금남로' 중심선(전일빌딩245·5·18기록관 사이) | 검증 |

| 04 ACC | OSM way/248192696(구역) 중심, spots.json acc(카카오 건물 좌표)와 55 m 차이 | 검증 |
| 05 금남로 나비정원 | OSM 동구 일대 '나비' 검색 결과 없음, 원본 사진 미확보 | **미확정 — 지도에 놓지 않음** |

본 사이트 `data/places.json`의 5·18민주광장 좌표는 실제 광장에서 약 387 m 떨어진 금남로3가(5·18기록관 옆)를 가리킵니다. 이 프로토타입은 OSM 값을 쓰며, 본 사이트 데이터는 건드리지 않았습니다(별도 수정 제안).

## 사진 레퍼런스의 쓰임

사용자가 준 캡처 10장은 분위기·밀도·시점 참고에만 썼고, 어떤 이미지도 사이트에 넣지 않았습니다. 사진 03(ACC 야경)의 남색 하늘·따뜻한 지평선·빛 상자가 전체 톤의 기준이고, 사진 01(충장로 야간)이 간판 상자의 근거입니다. 촬영점·방향이 미확정인 사진(04·05·08·09·10)은 대로 폭과 건물 밀도만 참고했습니다.

## 지도 위 '연출용' 요소 (실제 시설 위치가 아님)

- 금남로 가로등 점: 본선을 따라 32 m 간격으로 양쪽 13 m에 생성
- 충장로 간판 상자: 본선을 따라 17 m 간격, 양쪽 7.5 m, 높이 2.4–5 m
- ACC 빛 상자: 구역 폴리곤 안 24 m 격자

## 아직 안 된 것

- 금남로 나비정원 위치 확인(자료 보완 필요), 분수대 외 광장 세부, 건물 높이(98.4%가 자료 없음 → 단순화 모델)

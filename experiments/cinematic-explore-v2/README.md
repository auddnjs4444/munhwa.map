# 시네마틱 탐험 v2 (B안) — 실제 사진 + 2.5D 시차 + 장면 전환 (실험)

최종 콘셉트 PNG ②번을 **실제 광주 사진 중심**으로 다시 만든 실험입니다. 실시간 3D·위성지도 비행은 쓰지 않습니다(`experiment/city3d`, `experiment/city3d-v2`는 그대로 남겨 둠).

- 브랜치 `experiment/cinematic-explore-v2` (main 064398b 기준). **main 병합·배포 금지.** 운영 사이트 파일은 건드리지 않음.
- 열기: `python3 -m http.server 8010` (저장소 루트) → http://localhost:8010/experiments/cinematic-explore-v2/
- 주소: `#street` 충장로 거리로 바로, `#place/canmore` 캔모아 선택 상태로 바로. `?noanim=1` 전환 없이.

## 화면 전환 방식 (3D 비행이 아니라 사진 기반 컷)

- **내려가기(①→②, 2.1초)**: 도심 사진이 1.32배로 밀려 들어가며 어두워지고 흐려짐 + 레터박스 7% + 따뜻한 빛 번짐 + 자막 「충장로로 내려갑니다」, 동시에 거리 사진이 1.18배·흐림에서 또렷하게 디졸브. 두 사진의 시점이 다르므로 이어지는 카메라처럼 꾸미지 않고 컷으로 처리합니다.
- **올라가기(②→①, 1.7초)**: 거리 사진이 1.14배로 흐려지며 사라지고 도심이 돌아옵니다.
- **선택(②→③)**: 거리 사진 1.06배 확대 + 빛 번짐, 제목은 물러나고 카드가 올라옵니다.
- `prefers-reduced-motion`: 켄번스·시차 없음, 전환은 0.5–0.6초 페이드, 레터박스 없음.
- 사진 두 장을 먼저 내려받은 뒤 장면을 보여주므로 빈 화면이 없습니다(로딩 중 가는 금색 선).

## 데이터·사진

- 좌표·주소는 `data/spots.json` 그대로(캔모아 거점: 중앙로 172, 카카오맵·OSM 일치). 사진 위에 핀은 없습니다(촬영점·방향 미확정) — 장소 선택은 하단 칩·지역 선택 메뉴로.
- 사진은 사용 허락을 받은 블로그 사진의 709px 캡처본입니다. 켄번스는 1.04배, 전환 중 최대 1.32배까지만 확대합니다. **고화질 원본(도심 조망·충장로 거리)**이 들어오면 같은 경로에 바꿔 넣기만 하면 됩니다. 캔모아 자체의 사진은 없으며, 거리 사진을 캔모아 사진처럼 표시하지 않습니다(크레딧에 명시).

## 사진 보내실 때 (교체 규격)

파일을 `assets/explore/`에 아래 이름으로 넣으면 코드 수정 없이 바로 반영됩니다. 없는 파일은 자동으로 건너뜁니다.

| 파일 | 쓰임 | 권장 |
|---|---|---|
| `overlook-mountains.jpg` | ① 도심 조망 배경 (교체) | 가로, 긴 변 2,000px 이상, 해질녘이면 더 좋음 |
| `chungjang-night.jpg` | ② 충장로 거리 배경 (교체) | 가로, 2,000px 이상 |
| `canmore-street.jpg` | ③ 캔모아 선택 시 거리 위로 디졸브되는 캔모아 거리 사진 (신규) | 가로, 2,000px 이상, 캔모아 간판·입구가 보이는 거리 시점 |
| `canmore.jpg` | 카드 왼쪽 세로 사진과 하단 칩 썸네일 (신규) | 세로 또는 정방형, 짧은 변 800px 이상 |

- 촬영자·출처와 사용 허락 사실을 함께 알려주시면 크레딧에 그대로 적습니다. 과거 사진이면 촬영 시기도 적어 주세요.
- 사진은 저장소에 커밋되어 공개 사이트에 올라가므로, 허락이 확인된 사진만 보내 주세요.

## PNG ②와의 차이

- PNG는 생성형 야경 도시 위에 핀이 있지만, 여기서는 실제 낮 항공사진을 해질녘 톤으로 보정했고 핀 대신 하단 칩으로 장소를 고릅니다.
- 도시 조명의 입체감(창문 불빛)은 없습니다. 오른쪽 카메라 조작 UI(나침반·±·2D)는 사진 장면에 맞지 않아 두지 않았습니다.
- 이번 범위: 세 장면과 캔모아 연결까지. 다른 장소는 "다음 단계" 안내만.

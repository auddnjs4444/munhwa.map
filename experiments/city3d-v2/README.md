# 3D 도시 탐험 v2 — 실사 항공영상 + 지형 + OSM (실험)

최종 콘셉트 PNG ②번 "3D 도시 탐험 — 광주 동구"를 **실사 기반 하이브리드**로 만든 첫 장면입니다. 충장로·캔모아 주변만 다룹니다. 상자 도시(`experiment/city3d`)는 쓰지 않았고, 데이터(OSM 건물·도로·물·녹지, 검증 좌표)만 가져왔습니다.

- 브랜치 `experiment/city3d-v2` (main 064398b 기준). **main 병합·배포 금지.**
- 열기: `cd /Users/melong/수어지도 && python3 -m http.server 8010` → http://localhost:8010/experiments/city3d-v2/
- `#go/canmore` 캔모아 접근 상태로 바로 열기 · `?noanim=1` 카메라 애니메이션 없이 · `?vworld=KEY` 브이월드 항공영상 사용

## 무엇이 진짜 3D이고 무엇이 사진인가

| 요소 | 종류 | 출처 |
|---|---|---|
| 지형(무등산 능선·도심 기복) | 실제 3D (DEM, MapLibre terrain, 과장 1.25) | Mapzen Terrain Tiles (AWS Open Data, SRTM·NASA 기반) |
| 바닥 질감(건물 지붕·도로·녹지) | 실사 항공·위성영상 타일(지오레퍼런스, 낮 영상) | Esri World Imagery (키 없이 접근 가능, 표기 필수; 운영 사용 조건은 확인 필요). 브이월드(국토지리정보원, 25–50 cm, 키 필요)로 바꿔 끼울 수 있음 |
| 건물 부피 | 실제 3D (OSM 평면도를 높이로 올린 반투명 유리 부피; 높이는 OSM 값 → 없으면 용도별 추정) | OpenStreetMap (ODbL), `data/buildings.geojson` 1,159동 |
| 도로 조명선 | 연출 (실제 OSM 도로 중심선을 따라 따뜻한 빛. 가로등 위치가 아님) | OSM `data/roads.geojson` |
| 블루아워 색감 | 색보정 (영상 채도·밝기 낮춤 + 남색 틴트 + 하늘·안개) | — |
| 카메라 | 실제 3D 카메라 (기울기 60–62°, 회전, flyTo 4.6초, 도착 후 느린 회전) | MapLibre GL JS 4.7.1 |
| 핀 6개 | 좌표 확인된 장소에만 | `data/spots.json`(카카오맵·OSM 일치), `data/places.json`(5·18민주광장 보정값), 충우 앞 = OSM 광주우체국 |
| 거리 장면 | 실제 충장로 거리 사진(2.5D 시차, 켄번스) | `assets/explore/chungjang-night.jpg` (사용 허락 사진) — 카드의 「거리 사진」으로만 |

PNG의 건물 배치·장소 위치·야경 질감은 생성형이므로 복제하지 않았습니다. 사진 한 장으로 자유 카메라를 흉내 내지 않습니다(사진은 거리 장면과 썸네일에만).

## 흐름

1. 높은 곳에서 내려오며 **전체 조망**(충장로·금남로 일대를 가운데, 동쪽 무등산 방향). 제목 「광주 동구」, 핀 6개(겹치면 이름을 숨기고 점만), 하단 칩, 오른쪽 컨트롤(북쪽·전체 조망, +, −, 2D/3D).
2. **캔모아** 핀·칩·메뉴 선택 → 카메라가 4.6초에 걸쳐 충장로로 접근(줌 17.45, 기울기 62°) → 황금 카드(캔모아 · 충장로, 수어로 마음껏 이야기하던 곳 · 주소) → 「장소 기억 보기 →」가 기존 시네마틱 기록 화면 `explore.html#place/canmore`로 연결.
3. 「거리 사진」을 누르면 실제 충장로 거리 사진 장면, 「전체 조망」·Esc·북쪽 버튼으로 복귀.
4. 나머지 핀(충우 앞·궁전제과·금남로공원·5·18민주광장·ACC)은 좌표만 표시하고 다음 단계로 둡니다.

## 한계 (솔직하게)

- 바닥은 **낮에 찍은 영상을 어둡게 보정한 것**이라 PNG의 야경 질감(창문 불빛, 조명 반사)은 없습니다. 건물 벽면 질감도 없습니다(유리 부피만).
- 접근 줌(17 이상)에서는 영상 해상도 한계로 흐릿합니다. 브이월드 항공영상(키 필요)이면 더 선명합니다.
- 진짜 건물 질감을 얻으려면 실사 텍스처 3D 건물 데이터(브이월드 3D 등, 별도 신청·이용조건)가 필요합니다.
- 모바일은 레이아웃만 맞춰 두었고 성능·검증은 이번 범위 밖입니다.

# 손으로 부르는 광주 — 수어 지도 프로토타입

청년 ESG 문화실험실 프로젝트의 대표 산출물, 인터랙티브 「광주 수어 지도」의 시작 코드입니다.
지금 들어있는 데이터는 전부 **예시(placeholder)** 이며, 실제 인터뷰 데이터로 교체해야 합니다.

## 로컬에서 열어보기

브라우저 보안 정책 때문에 `index.html`을 더블클릭해서 바로 열면 `data/places.json`을 못 불러올 수 있습니다.
이 폴더 안에서 로컬 서버를 띄워서 열어주세요.

```bash
python3 -m http.server 8000
# 그 다음 브라우저에서
http://localhost:8000
```

Node가 편하면 `npx serve .` 도 됩니다.

## 파일 구조

- `index.html` — 페이지 뼈대와 스타일 (아카이브 / 지도 / 소개 3개 뷰)
- `app.js` — 아카이브 트랙·눈금자, 지도 초기화, 카드/핀 클릭 → 기록 오버레이 로직
- `data/places.json` — 장소 데이터. **인터뷰가 끝날 때마다 여기에 항목을 추가하세요.**

## 화면 구조

- **아카이브(기본)** — 가로로 넘기는 카드 트랙. 카드를 누르면 기록 오버레이가 열립니다.
  `video_youtube_id`를 채우면 카드에 유튜브 썸네일이 자동으로 뜹니다.
- **지도** — 핀을 누르면 같은 기록 오버레이가 열립니다.
- **소개** — 프로젝트 설명과 크레딧.

## 장소 데이터 추가하는 법

`data/places.json`에 아래 형태로 객체 하나를 추가하면 지도에 자동으로 핀이 생깁니다. 코드를 건드릴 필요는 없습니다.

```json
{
  "id": "고유한-영문-id",
  "name": "장소 이름",
  "lat": 35.xxxx,
  "lng": 126.xxxx,
  "video_youtube_id": "유튜브 영상 ID (일부공개로 업로드 후)",
  "origin_text": "수어 이름의 유래",
  "memory_text": "장소에 얽힌 기억",
  "tags": ["지정주제 태그", "세대 태그"],
  "sensitive": false
}
```

### 수어 영상 직접 올리기 (`videos`)

유튜브 대신 영상 파일을 직접 올릴 때는 `videos` 배열을 씁니다. 각도가 2개 이상이면 기록 화면에 전환 버튼(정면/측면)이 생기고, 첫 번째 영상의 `poster`가 아카이브 카드 썸네일이 됩니다.

```json
"videos": [
  { "label": "정면", "src": "media/장소id-front.mp4", "poster": "media/장소id-front.jpg" },
  { "label": "측면", "src": "media/장소id-side.mp4",  "poster": "media/장소id-side.jpg" }
]
```

- 촬영 원본은 `원본영상/`에 두세요 (`.gitignore` 처리되어 깃허브에 올라가지 않습니다).
- `media/`에는 **웹용 변환본만** 올립니다: 720p H.264 mp4, **오디오·GPS 메타데이터 제거**. 아이폰 원본에는 촬영 위치가 들어 있으니 원본을 그대로 올리지 마세요.

`tags`에 적은 값은 기록 오버레이 하단에 표시됩니다.
같은 주제는 표기를 통일해주세요 — 예를 들어 "문화접근성"과 "문화 접근성"은 서로 다르게 표시됩니다.

## 5·18 관련 지점 — 건드리지 말 것

`sensitive: true`인 항목은 카드가 바로 열리지 않고 안내 문구 + 버튼을 먼저 보여줍니다.
**관련 기관·유족 측 자문이 확보되기 전에는 `origin_text`, `memory_text`를 채우지 마세요.** (사업제안서 XI장 윤리 원칙)

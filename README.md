# 손으로 부르는 광주 — 수어 지도 프로토타입

청년 ESG 문화실험실 프로젝트의 대표 산출물, 인터랙티브 「광주 수어 지도」의 시작 코드입니다.
지금 들어있는 데이터는 전부 **예시(placeholder)** 이며, 실제 인터뷰 데이터로 교체해야 합니다.

## 로컬에서 열어보기

브라우저 보안 정책 때문에 `index.html`을 더블클릭해서 바로 열면 `data/places.json`을 못 불러올 수 있습니다.
이 폴더 안에서 로컬 서버를 띄워서 열어주세요.

```bash
python3 -m http.server 8000
# 그 다음 브라우저에서
http://localhost:8000
```

Node가 편하면 `npx serve .` 도 됩니다.

## 파일 구조

- `index.html` — 페이지 뼈대와 스타일 (기록(아카이브) / 지도(탐험 · 위치 보기, 지명 수어) / 소개 뷰). 상단 메뉴는 `explore.html`과 같다
- `app.js` — 아카이브 트랙·눈금자, 지도 초기화, 카드/핀 클릭 → 기록 오버레이 로직
- `spots.js` — 지도의 장소 둘러보기(거점·주변 장소·번호 핀·패널)
- `story.js` — 장소 기억(손글씨 편지 화면) 열기·닫기·쓰기 연출
- `data/places.json` — 장소 데이터. **인터뷰가 끝날 때마다 여기에 항목을 추가하세요.**
- `data/spots.json` — 거점과 주변 장소, `data/memory-stories.json` — 거점별 장소 기억 원문

## 화면 구조

- **아카이브(기본)** — 가로로 넘기는 카드 트랙. 카드를 누르면 기록 오버레이가 열립니다.
  `video_youtube_id`를 채우면 카드에 유튜브 썸네일이 자동으로 뜹니다.
- **지도** — 핀을 누르면 같은 기록 오버레이가 열립니다.
- **소개** — 프로젝트 설명과 크레딧.

## 장소 데이터 추가하는 법

`data/places.json`에 아래 형태로 객체 하나를 추가하면 지도에 자동으로 핀이 생깁니다. 코드를 건드릴 필요는 없습니다.

```json
{
  "id": "고유한-영문-id",
  "name": "장소 이름",
  "lat": 35.xxxx,
  "lng": 126.xxxx,
  "video_youtube_id": "유튜브 영상 ID (일부공개로 업로드 후)",
  "memory_text": "장소에 얽힌 기억",
  "tags": ["지정주제 태그", "세대 태그"],
  "sensitive": false
}
```

### 수어 영상 직접 올리기 (`videos`)

유튜브 대신 영상 파일을 직접 올릴 때는 `videos` 배열을 씁니다. 각도가 2개 이상이면 기록 화면에 전환 버튼(정면/측면)이 생기고, 첫 번째 영상의 `poster`가 아카이브 카드 썸네일이 됩니다.

```json
"videos": [
  { "label": "정면", "src": "media/장소id-front.mp4", "poster": "media/장소id-front.jpg" },
  { "label": "측면", "src": "media/장소id-side.mp4",  "poster": "media/장소id-side.jpg" }
]
```

- 영상이 1개면 전환 버튼 없이 바로 재생됩니다. `ratio`(가로÷세로, 예: 3:4 영상은 `0.75`)는 선택 항목으로, 적어두면 로딩 중 화면이 덜 흔들립니다.
- 촬영 원본은 `원본영상/`에 두세요 (`.gitignore` 처리되어 깃허브에 올라가지 않습니다).
- `media/`에는 **웹용 변환본만** 올립니다: 720p H.264 mp4, **오디오·GPS 메타데이터 제거**. 아이폰 원본에는 촬영 위치가 들어 있으니 원본을 그대로 올리지 마세요.

### 수어 표현 구성 (`sign_parts`)

수어 이름이 어떤 동작들로 이루어지는지 배열로 적습니다. 기록 화면에 `닭`, `화살 + 장소`처럼 표시되고, 소개 화면의 **SIGN INDEX** 목록에도 자동으로 들어갑니다.
자음 한 글자(`ㄱ`, `ㅊ` 등)는 자동으로 **지화**로 표시됩니다. 구성이 아직 다 확인되지 않았으면 `sign_parts_note`에 메모를 적으면 뒤에 `…`가 붙습니다.

```json
"sign_parts": ["ㄱ", "보성", "장소"],
"sign_parts_note": "나머지 구성은 확인 중입니다."
```

### 장소 기억 메모 (`memories`)

인터뷰 중 나온 짧은 이야기는 `memories` 배열에 넣으면 손글씨 메모 카드로 표시됩니다. `story`·`note`가 있으면 카드 오른쪽 위 `+`로 펼쳐집니다. `memories`가 없는 장소는 `memory_text` 문단을 그대로 씁니다. (`by`는 A·B 같은 익명 표기, `years`는 광주 거주 연수)

```json
"memories": [
  { "by": "A", "years": 23, "spot": "가게·장소명", "hand": "손글씨 한 줄(20자 안쪽)",
    "story": "긴 이야기(선택)", "note": "짧은 보충(선택)" }
]
```

### 인터뷰 장소 기억 (`memory_entries`)

구술 인터뷰처럼 긴 글은 `memory_entries` 배열에 넣습니다. 제목·부제·장소·참여자·본문·기억의 한마디가 접었다 펼치는 기록으로 표시되고, 한 지역에 여러 편을 넣으면 번호(01, 02…)로 구분됩니다. 본문 문단은 빈 줄(`\n\n`)로 나눕니다. 기존 `memories` 메모 카드·`memory_text`와 함께 쓸 수 있습니다.

```json
"memory_entries": [
  { "title": "충우 앞, 친구들과의 약속", "subtitle": "…", "location": "충장로우체국 앞",
    "narrator": { "name": "이인자", "identity": "농인", "origin": "전남 보성군 출생", "years": "광주 거주 45년 이상" },
    "text": "첫 문단…\n\n둘째 문단…", "quote": "기억의 한마디", "tags": ["충우앞", "충장로"] }
]
```

`tags`에 적은 값은 기록 오버레이 하단에 표시됩니다.
같은 주제는 표기를 통일해주세요 — 예를 들어 "문화접근성"과 "문화 접근성"은 서로 다르게 표시됩니다.

## 지도의 동 경계와 기록 연결

지도 화면은 `data/gwangju_donggu_sign_16.geojson`의 실제 경계(출처·기준일은 `data/BOUNDARIES.md`)를 그리고, 어느 경계가 어느 기록을 여는지는 **`data/dong-records.json`** 이 정합니다.

```json
"donggu_01": { "name": "계림동", "en": "GYERIM-DONG", "records": ["gyerim-dong"] }
```

- 동을 누르면 오른쪽 패널(모바일은 아래 시트)에 `records`에 적힌 기록이 열립니다. 비어 있으면 "아직 수집된 수어 기록이 없습니다"가 나옵니다. 여러 개면 목록에서 고릅니다.
- **새 영상을 추가할 때**: ① `media/`에 mp4·jpg를 넣고 ② `places.json`에 장소(또는 기존 장소의 `videos`)를 적고 ③ 해당 동의 `records`에 그 `id`를 넣으면 끝입니다. JavaScript는 손대지 않아도 됩니다.
- 경계 밖 장소(무등산·양림동·5·18민주광장)는 전처럼 핀으로 표시되고, 전체 화면 기록으로 열립니다.
- `#map/gyerim-dong`처럼 주소에 기록 id를 붙이면 그 기록이 열린 상태로 시작합니다.

## 지명 수어 화면 — v2 전시 지도 (`feature/sign-map-v2`)

지명 수어 보기는 차콜 바탕 위에 **동구 16개 동의 실제 경계**(`data/gwangju_donggu_sign_16.geojson`)가 주인공인 전시 지도입니다. 장소 둘러보기 모드의 색·배치에는 적용되지 않습니다(`body[data-map-mode="signs"]`로만 한정).

- **지도**: 지명 수어 보기에서는 OSM 타일 레이어를 지도에서 빼고(`app.js` `applySignsMap`, 장소 둘러보기로 돌아오면 복원) 차콜 바탕 위에 경계만 그립니다. 경계는 옅은 선 + 옅은 채움, 호버는 조금 밝게, 선택한 동은 따뜻한 금색(#C9A24B) 채움(CSS 클래스 `.hov`/`.sel`, 0.45초 전환). 경계 밖 핀(무등산·양림동·5·18민주광장)은 작은 금색 고리입니다. 가상의 도로·경계는 그리지 않습니다. 이 모드에서는 줌을 0.1 단위로 풀어(`zoomSnap`) 동구 전체가 빈 영역에 꼭 맞게 들어갑니다.
- **동 이름**: 넓은 동은 줌 12부터, 좁은 동은 14부터 보이고, 겹치는 라벨은 `collideLabels`가 넓은 동 우선으로 숨깁니다. 선택한 동의 이름은 줌과 상관없이 금색 위에 진하게 표시됩니다(`.dong-label.on`).
- **카메라**: `frameRegion`이 선택 동의 상자를 60% 키워 이웃 윤곽이 함께 보이게 한 뒤, 왼쪽 동 목록·오른쪽 패널·모바일 시트를 뺀 영역의 가운데에 놓습니다(정수 줌 11–14, flyTo 1.0초). `fitDistrict`는 16개 동 전체 구도이며, 지명 수어 보기로 바꾸거나 주소 `#map`으로 열면 이 구도로 시작합니다.
- **데스크톱(≥768px)**: 왼쪽 220px 동 목록(`#region-list`, 항상 표시, 내부 스크롤, 선택 행 금색, 호버 시 지도의 해당 동도 밝아짐) · 가운데 지도 · 오른쪽 400–460px 차콜 패널. 목록·지도 어느 쪽에서 골라도 서로 동기화됩니다.
- **모바일(≤767px)**: 목록은 숨기고 상단 「지역 선택 +」로 왼쪽 드로어를 엽니다. 고르면 드로어가 닫히고 → 동이 금색으로 → 카메라 이동 → 아래에서 영상 바텀시트(54dvh, 핸들로 88dvh까지). 시트가 열려 있어도 지도와 「지역 선택 +」를 계속 쓸 수 있습니다.
- **패널**: 깊은 차콜(장소 기억의 황금 패널과 구분). 동 이름 / 영문 / 「광주 동구 수어 지명 기록」 / 손글씨 한 줄(`sign_parts`를 그대로 ` · `로 이어 붙임, 문장을 만들지 않음) / 세로 수어 영상(3:4, `object-fit: contain`, 기존 `media/*.mp4`) / 기록·경계·영상 사실 3칸 / 수어 표현 구성 칩 / 이름의 유래(`origin_text`가 비면 "아직 확인된 설명이 없습니다") / 태그. 5·18 지점은 열람 확인 문구를 먼저 보여줍니다.
- 주소: `#map/<id>`(기존 그대로), `#map`(동구 전체 보기). `#spot/…`·`#spots`는 장소 둘러보기. 상단 메뉴 「지명 수어」는 `#map`으로 들어오고, 이 보기에서는 탐험의 「거리 보기 | 위치 보기」 토글을 보이지 않습니다(돌아갈 때는 상단 메뉴 「탐험」).

## 장소 둘러보기 (거점과 주변 장소) — `data/spots.json`

지도 화면은 **장소 둘러보기**(탐험 · 위치 보기, 주소 `#spots`·`#spot/…`)와 **지명 수어**(동 경계·동 목록·수어 영상, 주소 `#map`·`#map/…`) 두 보기입니다. 전환은 상단 메뉴(탐험 ↔ 지명 수어)로 하고, 장소 둘러보기 위의 「거리 보기」는 `explore.html`로 보던 장소를 그대로 넘깁니다(`spots.js` `streetHref`). 장소 둘러보기의 거점 3곳과 주변 장소는 `data/spots.json`에서 관리합니다.

- `hubs[]` — 거점. `explore: true`면 '주변 둘러보기' 버튼이 생기고 `nearby[]`의 id가 작은 핀과 목록으로 나옵니다. `intro`(소개), `contact`(확인한 소통 정보 + 확인일), `pending_note`(안내문), `photo`(사진 경로, 없으면 영역 생략), `sign_place`(지명 수어의 장소 id, 정확히 대응될 때만).
- `places[]` — 주변 장소. `address`, `geo{lat,lng,precision,source,note}`, `related[]`(함께 소개할 곳), `photo`.
- `geo.precision`이 `poi`/`building`일 때만 지도에 핀을 찍습니다. 좌표가 없으면 목록에 **위치 확인 중**으로 남습니다. 좌표 출처는 `geo.source`/`geo.note`에 남깁니다.
- 주소는 `#spot/<거점id>`, `#spot/<거점id>/nearby`, `#spot/<거점id>/<장소id>`로 복원됩니다.

## 장소 기억 (거점의 이야기) — `data/memory-stories.json`

거점 패널의 **장소 기억** 버튼을 누르면 지도 위로 손글씨 편지 화면이 겹쳐지고, 글이 한 글자씩 쓰입니다. 원문은 `data/memory-stories.json`에 거점 id를 키로 넣습니다. 이야기가 있는 거점에만 버튼이 생깁니다 (지금은 `canmore` 하나).

```json
"canmore": {
  "title": "손끝으로 나누던 우리의 이야기",
  "subtitle": "충장로 캔모아 · 장소 기억",
  "paragraphs": ["문단 1", "문단 2", "…"],
  "emphasis": [10, 12]
}
```

- `paragraphs` — 문단 배열. 원문 그대로 넣고 문단 단위로만 나눕니다.
- `emphasis` — 조금 크게 보여줄 문단 번호(1부터). 마지막 문단이 포함되면 금빛 선과 함께 맺음 문단으로 표시됩니다.
- 종이를 누르거나 Enter를 치면 쓰고 있는 문단이 바로 완성되고, 아래쪽 **건너뛰기**로 전체를 한 번에 볼 수 있습니다. 다음 문단이 화면 아래에 있으면 스크롤해서 내려올 때 이어 씁니다.
- 닫기(✕, 지도로 돌아가기, Esc, 브라우저 뒤로 가기) 뒤에는 지도 위치·줌·열려 있던 패널이 그대로 남습니다. 주소는 `#spot/<거점id>/story`로 바로 열립니다.
- 시스템의 **동작 줄이기**가 켜져 있으면 쓰기 연출 없이 전체 글이 바로 보입니다.
- 지명 수어 패널에서는 `memories`(농인의 기억) 영역을 보여주지 않습니다. 데이터는 그대로 두었고 아카이브 기록 화면에는 계속 표시됩니다.

## 5·18 관련 지점 — 건드리지 말 것

`sensitive: true`인 항목은 카드가 바로 열리지 않고 안내 문구 + 버튼을 먼저 보여줍니다.
**관련 기관·유족 측 자문이 확보되기 전에는 `memory_text`·`memories`를 채우지 마세요.** (사업제안서 XI장 윤리 원칙)

## 사이트 구조 (A안, 2026-10-19 통합) — 탐험 · 지명 수어 · 기록 · 소개

두 페이지가 한 메뉴를 씁니다. `explore.html` = **탐험 · 거리 보기**(첫 화면 포함), `index.html` = **탐험 · 위치 보기**(장소 지도) + **기록**(아카이브) + **소개**. 상단 메뉴는 두 페이지에서 같고(탐험 페이지는 「지도」, index.html은 「탐험」으로 표기 · 기록 · 소개), 탐험 안에서만 「거리 보기 | 위치 보기」를 전환합니다. **지명 수어 지도(`#map`)는 2026-10-22에 메뉴와 패널 링크에서 뺐습니다** — 주소 `#map`·`#map/<id>`로는 그대로 열리지만 화면 어디에도 들어가는 버튼이 없습니다. 지명 수어 기록은 「기록」 화면의 카드로 보고, 카드에 올리거나 누르면 왼쪽 아래 동구 미니맵에서 그 기록의 동이 금색으로 빛납니다(실제 경계 `data/gwangju_donggu_sign_16.geojson` + 연결표 `data/dong-records.json`; 경계가 없는 무등산·양림동·5·18민주광장은 좌표 점). 새 화면을 만들지 않고 기존 두 페이지를 메뉴·주소·상태 전달로 이었습니다.

- **사용자 흐름**: 첫 화면 → 「광주 탐험하기」(내려가기 컷 2.1초) → **충장로 거리**(`#explore`: 거리 사진 액자 + 장소 기억 원문 한 문단 + 장소 칩) → 캔모아 칩 → **캔모아 상세**(`#place/canmore`: 황금 패널, 농인의 장소 기억이 맨 위) → 「이야기 전체 읽기」 또는 「장소 기억 전체 화면으로」(`index.html#spot/canmore/story`, 손글씨 편지 화면).
- **거리 보기 ↔ 위치 보기**: 보던 장소를 그대로 넘깁니다. `explore.html#place/canmore` → 「위치 보기」 → `index.html#spot/canmore`; 장소 지도에서 「거리 보기」 → `explore.html#place/<보던 장소>`. 장소 지도에 없는 곳(충우 앞·5·18민주광장 등)은 지명 수어 지점(`#map/<id>`)으로, 아무것도 고르지 않았으면 `#spots` / `#explore`로 갑니다.
- **메뉴 대상**: 탐험(지도) → `explore.html#explore`(같은 탭에서 보던 거리 보기 상태가 있으면 그 주소로, `sessionStorage` `cine:last`) · 기록 → `index.html?view=archive` · 소개 → `index.html?view=about`. 활성 표시는 `syncNav`. (`spots.js` `goSigns`는 남아 있지만 메뉴에서 부르지 않습니다.)
- **주소**: `explore.html`(첫 화면) · `#explore`(충장로 거리) · `#place/<id>` / `index.html#spots`(거점 전체, 새 주소) · `#spot/<거점>[/<장소>|/nearby|/story]` · `#map`(동구 전체) · `#map/<id>` · `?view=archive|about|map`. 기존 주소는 모두 그대로입니다. `#map`은 지명 수어 전체 보기 전용이라 장소 지도 전체 보기에는 `#spots`를 새로 썼습니다.
- **뒤로 가기·새로고침**: `explore.html` 안에서 앞으로 가는 이동(탐험하기·장소 선택)은 history에 남아 뒤로 가기로 이전 장소·화면이 복원됩니다(닫기는 주소만 바꿈). 페이지 사이 이동은 주소로 복원되고, `index.html`은 패널을 닫아도 보기 주소(`#map`/`#spots`)를 남겨 새로고침해도 첫 화면으로 튀지 않습니다(종전엔 `#map`으로 열면 주소가 지워졌음). 장소 기억 화면은 전처럼 뒤로 가기 한 번이면 닫힙니다.
- **사진**: 거리·ACC 사진(709px)은 전체 화면으로 늘리지 않고 원본 비율의 액자(데스크톱 높이 42vh ≈ 원본 0.8배, 모바일 가로 전체 = 원본보다 작게)로 보여주고 흐림·색보정을 쓰지 않습니다. 첫 화면 배경만 종전대로 전체 화면입니다. 모바일은 액자가 위, 제목·인용이 아래, 칩이 맨 아래(높이 700px 이하에서는 인용 생략).
- **농인의 기억**: 충장로 거리 화면의 인용은 `data/memory-stories.json` 캔모아 원고 첫 문단을 원문 그대로 보여주고 출처와 '전시용으로 고쳐 쓰지 않음'을 적습니다. 장소 패널은 「농인의 장소 기억」을 「장소 정보」보다 위에 둡니다. 기록이 없는 장소 칩은 점선·「준비 중」으로, 5·18민주광장은 「열람 확인」으로 표시합니다(안내문 유지).
- **보관**: `experiment/cinematic-explore-v2`(사진 전환 실험; 전환 효과는 여기에 반영됨), `experiment/city3d`, `experiment/city3d-v2`(개발 중단, 삭제하지 않음).

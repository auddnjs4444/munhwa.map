# 손으로 부르는 광주 — 수어 지도 프로토타입

청년 ESG 문화실험실 프로젝트의 대표 산출물, 인터랙티브 「광주 수어 지도」의 시작 코드입니다.
지금 들어있는 데이터는 전부 **예시(placeholder)** 이며, 실제 인터뷰 데이터로 교체해야 합니다.

## 로컬에서 열어보기

브라우저 보안 정책 때문에 `index.html`을 더블클릭해서 바로 열면 `data/places.json`을 못 불러올 수 있습니다.
이 폴더 안에서 로컬 서버를 띄워서 열어주세요.

```bash
python3 -m http.server 8000
# 그 다음 브라우저에서
http://localhost:8000
```

Node가 편하면 `npx serve .` 도 됩니다.

## 파일 구조

- `index.html` — 페이지 뼈대와 스타일
- `app.js` — 지도 초기화, 데이터 불러오기, 핀 클릭 → 카드 렌더링 로직
- `data/places.json` — 장소 데이터. **인터뷰가 끝날 때마다 여기에 항목을 추가하세요.**

## 장소 데이터 추가하는 법

`data/places.json`에 아래 형태로 객체 하나를 추가하면 지도에 자동으로 핀이 생깁니다. 코드를 건드릴 필요는 없습니다.

```json
{
  "id": "고유한-영문-id",
  "name": "장소 이름",
  "lat": 35.xxxx,
  "lng": 126.xxxx,
  "video_youtube_id": "유튜브 영상 ID (일부공개로 업로드 후)",
  "origin_text": "수어 이름의 유래",
  "memory_text": "장소에 얽힌 기억",
  "tags": ["지정주제 태그", "세대 태그"],
  "sensitive": false
}
```

`tags`에 적은 값은 지도 위 **세대·주제 필터 칩으로 자동 노출**됩니다.
같은 주제는 표기를 통일해주세요 — 예를 들어 "문화접근성"과 "문화 접근성"은 서로 다른 칩이 됩니다.

## 5·18 관련 지점 — 건드리지 말 것

`sensitive: true`인 항목은 카드가 바로 열리지 않고 안내 문구 + 버튼을 먼저 보여줍니다.
**관련 기관·유족 측 자문이 확보되기 전에는 `origin_text`, `memory_text`를 채우지 마세요.** (사업제안서 XI장 윤리 원칙)
